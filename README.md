## 二、影展專題介紹

本次影展以「不期而驛，驛猶未盡」為主題，
以臺中驛鐵道文化園區為主要策展場域。

透過三代車站的歷史、鐵道文化與城市記憶，
呈現臺中車站不同時代的故事。

「不期而驛」象徵每一次進站都是不期而遇的風景；
「驛猶未盡」則代表鐵道文化的故事仍在延續。

## 三、Vibe Coding 使用說明

本專題使用 ChatGPT 輔助網頁製作，
透過自然語言指令（Prompt），
逐步完成網站架構、視覺設計與功能調整。

### Prompt 1：建立網站架構

請以「不期而驛，驛猶未盡」為主題，
製作一個完整的影展專題網站。

網站需要包含：
- 上方導覽列
- 側邊資訊欄
- 多個 HTML 分頁
- 策展理念介紹
- 三代車站介紹
- 三大主題展區
- 個人資料與劇務工作內容

### Prompt 2：網站視覺設計

請將網站設計為現代文青簡約風格。

主要配色使用：
- 米白色
- 鼠尾草綠
- 深森林綠

希望網站具有大量留白、
簡約字體與精緻的內容卡片。

### Prompt 3：Grid System

請使用 CSS Grid System
建立左右雙欄的網頁排版。

左側顯示主要文章，
右側顯示影展資訊與劇務內容。

### Prompt 4：RWD 響應式設計

請製作 RWD 響應式網頁，
讓網站可以在電腦、平板及手機上觀看。

手機版需要完整顯示資訊，
並保留上方可直接點擊的導覽列，
不使用漢堡選單。

### Prompt 5：CSS 檔案切割

請將 CSS 分成以下檔案：

- base.css
- layout.css
- components.css
- responsive.css
- modern-theme.css

所有 CSS 放在 css 資料夾內。

### Prompt 6：SEO 優化

請加入網站 SEO 設定，包括：

- title
- meta description
- keywords
- author
- viewport
- 圖片 alt 替代文字
- 語意化 HTML 標籤

### Prompt 7：圖片管理

請將台中驛相關圖片
統一放在 images 資料夾，
並在 HTML 中使用相對路徑。

### Prompt 8：網站細節修改

請在劇務工作內容下方，
新增「觀展小叮嚀」卡片。

並在網站頁尾加入
置中、有底線的「回到首頁」連結。

首頁標題需要縮小字體，
使標題盡量保持在同一行。
